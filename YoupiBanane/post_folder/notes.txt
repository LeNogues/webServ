TO PULL A REMOTE BRONCH TO THE LOCAL
	git switch -c <branchname> origin/<branchname>

TO PUSH A LOCAL BRANCH TO THE REMOTE
	git push -u origin <branchname>

TO SET A REMOTE FOR A REPO
	git remote add origin <repo-url>
